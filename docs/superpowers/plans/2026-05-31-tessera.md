# Tessera Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A client-side Next.js collage maker that packs 30–50 event photos into seamless, face-aware collages, reorderable by drag/AI/chat, with text reflow and high-res PNG/JPG export tuned for LinkedIn.

**Architecture:** Most logic lives in client components driven by a Zustand store. Three pure modules (layout engine, carousel distribution, crop math) are unit-tested. An image pipeline decodes off-thread to lightweight previews and keeps originals only for canvas export. A swappable AI provider (OpenAI, BYOK) runs on cached per-photo metadata.

**Tech Stack:** Next.js (App Router) + TypeScript + Tailwind, Zustand, dnd-kit, idb, openai, Vitest for unit tests.
